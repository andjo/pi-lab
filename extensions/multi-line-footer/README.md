# multi-line-footer (pi extension)

Replaces the default footer with a richer multi-line footer showing:

- **Line 1:** Working directory, git branch, and session name
- **Line 2:** Token usage (input/output), cache read/write, cost, context window usage with color-coded percentage, and model info (with provider and thinking level)
- **Line 3:** Status messages from other extensions (sorted alphabetically)
- **Line 4:** VS Code integration status (if active, on its own line)
